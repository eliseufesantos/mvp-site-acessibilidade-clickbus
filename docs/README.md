## Conceitos visuais

Os arquivos em `concepts/` representam os quatro estados que orientaram a implementação:

1. home e busca no modo padrão;
2. resultados com alto contraste;
3. seleção de assento no modo idoso;
4. checkout simulado com os dois modos combinados.

Essas imagens são referências de direção visual. A aplicação final prioriza comportamento responsivo, navegação por teclado e estados reais dos componentes.
